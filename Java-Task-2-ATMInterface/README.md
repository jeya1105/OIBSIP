# ATM Interface

## About
A console-based ATM application developed using Java.

## Features
- User ID and PIN authentication
- Account balance enquiry
- Deposit and withdrawal
- Money transfer between sample accounts
- Transaction history
- Access denied after three incorrect login attempts

## Technologies
- Java
- Object-Oriented Programming
- ArrayList and HashMap
- VS Code

## How to Run
Compile:
javac *.java

Run:
java Main

## Sample Login
User ID: JEYA101
PIN: 1234

Note: This project uses sample account data.
It does not connect to a real bank account.
