# Number Guessing Game

## About the Project
This is a console-based Number Guessing Game developed using Java.

The computer generates a random number between 1 and 100.
The player has a maximum of 7 attempts to guess the number.

## Features
- Random number generation
- Too High and Too Low hints
- Maximum 7 attempts
- Displays the correct number if the player loses
- Play Again option
- Final score tracking across rounds

## Technologies Used
- Java
- Scanner class
- Random class
- VS Code

## How to Run

Compile the program:
javac NumberGuessingGame.java

Run the program:
java NumberGuessingGame
